00 / C++ · Tree-sitter Taint Analysis Security pgvector

Sentinel: Static
Analysis Engine

A source-code security scanner that finds injection vulnerabilities by tracing untrusted input all the way to dangerous sinks. The C++ worker parses each file into a real syntax tree with Tree-sitter and runs taint analysis to a fixpoint over the AST, so flows are caught regardless of statement order, and comments or string literals never trigger false findings. A Python + pgvector layer then suppresses known false positives by similarity-matching against previously dismissed results. Supports JavaScript, Python, and Go, with sources and sinks declared per language so new rules drop in cleanly.

01 Ingest Go + Fiber gateway queues scan jobs
02 Parse AST Tree-sitter · JS · Python · Go
03 Taint to Fixpoint source → sink dataflow on the tree
04 Report Sinks calls & writes reached by tainted data
05 FP Suppression pgvector similarity vs dismissed findings

01 / PyTorch Computer Vision FastAPI

Alzheimer's MRI
Progression Classifier

An end-to-end deep-learning app that grades Alzheimer's progression from axial brain MRI scans. A fine-tuned ResNet-18 CNN (transfer learning in PyTorch) classifies each scan into four clinical stages (Non / Very Mild / Mild / Moderate Demented), reaching 95%+ validation accuracy. Training and test sets are physically isolated on disk to guarantee zero data leakage, and an asynchronous FastAPI backend serves real-time inference to a drag-and-drop web dashboard that renders live Softmax confidence for each class.

ResNet-18 11.7M params

02 / Go · Gin Fintech PostgreSQL

AtomicBank: Fintech
Ledger Backend

A high-throughput banking backend built in Go that treats correctness and security as non-negotiable. Instead of overwriting balances, every movement is recorded in an immutable double-entry ledger and balances are computed from the debit/credit history, creating a permanent, auditable trail where transactions are strictly atomic.

  • Race-condition immunity: row-level FOR UPDATE locking and serialized transactions block double-spending.
  • Zero-trust REST API: Gin middleware injects the authenticated context to neutralize IDOR exploits.
  • Context-aware lifecycle: a dropped client connection aborts and rolls back the in-flight transaction.
  • ACID storage: PostgreSQL / CockroachDB for distributed, consistent SQL.

04 / C++ Machine Learning NLP

NLP Tag Classifier
in C++

For my Programming and Introductory Data Structures course (EECS 280), I built a machine learning algorithm in C++ that predicts the tag attached to a forum post. It uses a bag-of-words technique: tallying word frequencies across posts with known tags using maps, computing a log-probability score per word per tag, then summing those scores across every word in a new post to identify its most likely tag.

87.08% Accuracy
